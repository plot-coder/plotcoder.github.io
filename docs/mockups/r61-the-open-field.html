For the agent

The four tools that set the fields take open beside the value: set_logline { open: "two candidates, not chosen" }, set_premise { open: "…" }, set_when { ids, open: "…" }, rename_board { open: "…" }. Setting a value clears the open words; open: "" closes the field with no value, so it is blank again, as a card's open: "" does. new_project and new_board take open for the board's name, so a board born from a maybe is born open and not "Board 1". The words are free text, as a card's are, and the guide says the same thing about them: only on the writer's word, never to fill a field the agent could not decide.
