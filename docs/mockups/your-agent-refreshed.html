3 · Is this the best we can do?

The asks. The four chips are the app's workflows, which already exist in Reminders with their sentences. Putting them here means a writer with an agent never has to wonder what to say. It is the part of this I would keep if everything else were cut.
"Done, next" is the writer's word, not a check. The app cannot see into Claude's settings. The only proof is the agent arriving, which is what turns the head green.
Still the header. Step 2 is three things to copy where it should be one button. That is the door's sign-in (R72), which waits on the dashboard setting. This refresh makes the header as plain as it can be; it does not make it go away.
The password field stays. Without it a newcomer has to make the header's value by hand, which is worse. The field is labelled for what it makes, and the Copy beside it wakes only when there is something to copy.

What a yes means. The sheet as drawn: the head as the state, what to say and the four asks when an agent has been, three steps with one open when none has, step 4 gone.
